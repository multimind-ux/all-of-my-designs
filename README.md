# All of my designs

Quickshell desktop designs adapted for a **Caelestia + Hyprland** setup.

These are my own desktop designs, built and maintained by multimind-ux (Abdulbasit) for a Caelestia + Hyprland setup. They run as standalone Quickshell configs alongside Caelestia instead of replacing its shell.

## What's inside

| Folder | Description |
| --- | --- |
| `quickshell/wifi-panel` | Wi-Fi panel with network list, live rx/tx throughput, and Cloudflare speedtest. `SUPER+H`. |
| `quickshell/notif-island` | Permanent top-center Dynamic Island with PixelBot, now playing, CPU/network/battery, clock, and notification popups. `SUPER+SHIFT+N`. |
| `quickshell/wall-clock` | Full DesktopClock stack: wallpaper, wallpaper-frosted Iceberg time, optional subject cutout in front, and bottom date. |
| `quickshell/lockscreen` | Full lockscreen stack: clock, quote, music, weather, stats, uptime, recent notifications, and PAM password field. `SUPER+L`. |
| `assets/pixelbot` | PixelBot mood sounds. |
| `scripts/cava-*.conf` | Lightweight cava configs used by the lockscreen visualizer and available for the island. |
| `scripts/wallcut` | Generates the clock blur, optional rembg cutout, and 32×18 placement grid. |
| `assets/fonts` | Iceberg font used by the wallpaper clock and SDDM theme. |
| `sddm/elarun-custom` | Terminal-style SDDM login screen (Prompt) with a fixed cool-dark palette. |
| `scripts/sync-caelestia-colors` | Exports Caelestia's wallpaper-derived scheme to `~/.config/quickshell/colors.css`. |

## Install

```bash
git clone https://github.com/multimind-ux/all-of-my-designs.git
cd all-of-my-designs
./install.sh
```

Then merge the snippets in `hyprland/` into your Caelestia Hyprland Lua config and reload:

```bash
hyprctl reload
```

## Run manually

```bash
qs -c wifi-panel -n -d
qs -c notif-island -n -d
qs -c wall-clock -n -d
qs -c lockscreen -n -d
```

## IPC

```bash
qs -c wifi-panel ipc call wifi toggle
qs -c notif-island ipc call island toggle
qs -c notif-island ipc call bot status
qs -c wall-clock ipc call wallclock state
qs -c wall-clock ipc call wallclock regen
qs -c lockscreen ipc call lockscreen lock
qs -c lockscreen ipc call lockscreen lockTimed 3
```

## Notes

- The Wi-Fi panel and lockscreen read `~/.config/quickshell/colors.css`, generated by `sync-caelestia-colors`.
- The notification island and lockscreen read Caelestia's notification history from `~/.local/state/caelestia/notifs.json`; they do not start a second notification daemon.
- The wallpaper clock reads Caelestia's wallpaper from `~/.local/state/caelestia/wallpaper/path.txt` and regenerates assets in `~/.cache/wallcut/`. `rembg` is optional: without it the frosted glass still works, but no subject cutout is drawn.
- The lockscreen PAM service lives at `~/.config/quickshell/lockscreen/pam/quickshell-lock` and uses `pam_unix.so` auth only.
- Paths in `quickshell/lockscreen/lockscreen.json` support `~` and `$HOME`.

## SDDM login theme (Prompt)

The `sddm/elarun-custom/` directory is the terminal-style login screen ported
adapted by multimind-ux. It uses a fixed cool-dark palette (matching
the notification island) and a copy of the current Caelestia wallpaper, so it
does not depend on matugen.

Install it with root privileges:

```bash
sudo ./install-sddm-theme.sh
```

It copies the theme to `/usr/share/sddm/themes/elarun-custom` and writes
`/etc/sddm.conf.d/50-prompt-theme.conf`. The theme is used on the next login or
reboot; SDDM is not restarted by the script so your current session is not
interrupted.
